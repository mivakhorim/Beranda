## ⚡ Panduan 1-Klik Upload ke GitHub Pages

### Cara 1 (Otomatis & Tercepat via Script):
1. Buka folder `dist-github-pages/`.
2. Klik ganda file **`deploy-to-github.bat`**.
3. Masukkan URL repositori GitHub Anda saat diminta.
4. Selesai! Seluruh data otomatis ter-push ke GitHub.

### Cara 2 (Manual via Web Browser GitHub):
1. Buka repositori GitHub Anda di browser (misal: `https://github.com/username/dutamik-id`).
2. Klik tombol **Add file** -> **Upload files**.
3. Seret (*drag & drop*) **seluruh isi dalam folder `dist-github-pages/`** ke halaman browser.
4. Klik **Commit changes**.

---

## ⚙️ Pengaturan di Repositori GitHub:
1. Masuk ke tab **Settings** di repo GitHub.
2. Di menu kiri, klik **Pages**.
3. Pada **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `root`
   - Klik **Save**.
4. Dalam 1-2 menit, website live aktif di `https://dutamik.id` atau `https://username.github.io/dutamik-id/`.
